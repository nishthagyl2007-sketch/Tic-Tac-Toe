# 🎮 Tic Tac Toe

A simple and interactive **Tic Tac Toe** game built using **HTML, CSS, and JavaScript**. The project focuses on creating a clean user interface along with smooth game interaction and dynamic game logic.

## ✨ Features

* 🎯 Two-player Tic Tac Toe gameplay
* 🔄 Automatic turn switching between players
* 🏆 Win detection
* 🤝 Draw/tie detection
* 🔁 Restart/New Game functionality
* 📱 Responsive design
* 🎨 Clean and user-friendly interface

## 🛠️ Technologies Used

* **HTML5** — Structure of the game
* **CSS3** — Styling and responsive layout
* **JavaScript** — Game logic and interactivity

## 🎮 How to Play

1. Player X starts the game.
2. Players take turns selecting an empty cell.
3. The first player to get three matching symbols in a row, column, or diagonal wins.
4. If all cells are filled without a winner, the game ends in a draw.
5. Start a new game to play again.
